══════════════════════════════════════════════════════════════
                 GIT & GITHUB COMMAND CHEAT SHEET
══════════════════════════════════════════════════════════════

1. CLONE / SETUP
──────────────────────────────────────────────────────────────

Clone repository:
git clone <repository-URL>

Enter repository:
cd <repository-name>

Check remote:
git remote -v

Change remote URL:
git remote set-url origin <repository-URL>


2. STATUS / CHANGES
──────────────────────────────────────────────────────────────

Check all changes:
git status

Unstaged differences:
git diff

Staged differences:
git diff --staged

Compare two branches:
git diff main..feature/branch

Compare specific file:
git diff main..feature/branch -- path/to/file


3. BRANCHES
──────────────────────────────────────────────────────────────

Show local branches:
git branch

Show local + remote branches:
git branch -a

Show remote branches:
git branch -r

Create branch:
git branch <branch-name>

Create + switch:
git switch -c <branch-name>

Switch branch:
git switch <branch-name>

Old way to switch:
git checkout <branch-name>

Delete local branch:
git branch -d <branch-name>


4. ADD / COMMIT
──────────────────────────────────────────────────────────────

Add one file:
git add <file>

Add all files:
git add .

Commit:
git commit -m "message"

View history:
git log

Compact history:
git log --oneline

Latest commit:
git log -1

Show commit:
git show <commit-id>


5. AMEND LAST COMMIT
──────────────────────────────────────────────────────────────

Add forgotten file to previous commit:

git add <file>
git commit --amend --no-edit

--no-edit = keep original commit message


6. FETCH / PULL / PUSH
──────────────────────────────────────────────────────────────

Download remote changes WITHOUT merging:
git fetch origin

Fetch + merge remote main:
git pull origin main

Push main:
git push origin main

Push a new branch:
git push -u origin <branch-name>


REMEMBER:

fetch = DOWNLOAD
pull  = DOWNLOAD + INTEGRATE
push  = UPLOAD


7. MERGE
──────────────────────────────────────────────────────────────

Switch to main:
git switch main

Merge feature:
git merge feature/tenant-registration

After fixing conflicts:
git add .
git commit


8. REBASE
──────────────────────────────────────────────────────────────

Switch to feature:
git switch feature/tenant-registration

Rebase onto main:
git rebase main

After fixing conflict:
git add <file>
git rebase --continue

Cancel rebase:
git rebase --abort


REMEMBER:

merge  = combine branches
rebase = move feature commits onto another branch


9. REVERT
──────────────────────────────────────────────────────────────

Safely undo a commit:
git revert <commit-id>

Revert creates a NEW commit.
Original history is preserved.


10. RESET
──────────────────────────────────────────────────────────────

Undo last commit + KEEP changes STAGED:
git reset --soft HEAD~1

Undo last commit + KEEP changes UNSTAGED:
git reset --mixed HEAD~1

Undo last commit + DELETE changes:
git reset --hard HEAD~1

⚠️ Be careful with --hard.


11. STASH
──────────────────────────────────────────────────────────────

Save unfinished changes:
git stash

View stashes:
git stash list

Restore latest stash + remove it:
git stash pop

Restore stash but keep it:
git stash apply

Delete a stash:
git stash drop


12. REMOVE FILE FROM GIT BUT KEEP LOCALLY
──────────────────────────────────────────────────────────────

git rm --cached <file>

Example:
git rm --cached src/main/resources/db-config.env

Add to .gitignore if needed:
echo "src/main/resources/db-config.env" >> .gitignore


13. HISTORY / GRAPH
──────────────────────────────────────────────────────────────

Full history:
git log

Compact history:
git log --oneline

Visual branch timeline:
git log --oneline --graph --all

Latest commit:
git log -1

Show commit details:
git show <commit-id>


14. BRANCH INFORMATION
──────────────────────────────────────────────────────────────

Current branch:
git status

Local branches:
git branch

Local + remote:
git branch -a

Remote only:
git branch -r

Branches + latest commits:
git branch -av


15. GITHUB REMOTE
──────────────────────────────────────────────────────────────

Check remote:
git remote -v

Add remote:
git remote add origin <URL>

Change remote:
git remote set-url origin <URL>

Fetch:
git fetch origin

Push:
git push origin main

══════════════════════════════════════════════════════════════
                     SSH KEY CREATION
══════════════════════════════════════════════════════════════

1. Generate SSH key
───────────────────
ssh-keygen -t ed25519 -C "your-email@example.com"


2. When asked:

Enter file in which to save the key:
Press ENTER

Enter passphrase:
You can enter a password OR press ENTER for no passphrase.

Enter same passphrase again:
Enter it again OR press ENTER.


3. Start SSH Agent
───────────────────
eval "$(ssh-agent -s)"


4. Add SSH private key to agent
───────────────────────────────
ssh-add ~/.ssh/id_ed25519


5. Display your PUBLIC key
───────────────────────────
cat ~/.ssh/id_ed25519.pub


6. Test GitHub SSH connection
─────────────────────────────
ssh -T git@github.com


Expected result is similar to:

Hi <username>! You've successfully authenticated...

══════════════════════════════════════════════════════════════
                 USE SSH WITH GIT
══════════════════════════════════════════════════════════════

Clone using SSH:

git clone git@github.com:USERNAME/REPOSITORY.git


Change existing repository from HTTPS to SSH:

git remote set-url origin git@github.com:USERNAME/REPOSITORY.git


Check:

git remote -v


Expected:

origin  git@github.com:USERNAME/REPOSITORY.git (fetch)
origin  git@github.com:USERNAME/REPOSITORY.git (push)


══════════════════════════════════════════════════════════════
                  HTTPS vs SSH
══════════════════════════════════════════════════════════════

HTTPS:
git clone https://github.com/USERNAME/REPOSITORY.git

SSH:
git clone git@github.com:USERNAME/REPOSITORY.git


SSH is useful because after setting up the key,
you don't normally need to enter your GitHub password
for every Git operation.
